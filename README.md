# OpenDesk

Free remote desktop for **Windows 10/11** and **Ubuntu**. Type someone's 9-digit ID, they click **Accept**, and you can see and use their computer from anywhere.

**Website and downloads:** https://kanthurijaswanth.github.io/opendesk/

Installers are on the [Releases](https://github.com/kanthurijaswanth/opendesk/releases) page. This repository holds the website.
